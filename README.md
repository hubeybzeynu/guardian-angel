# FileLink downloads

Installer files for [FileLink](https://filelinkhub.vercel.app): the Desktop App, the Setup wizard and the MSI.
Download them from the [latest release](../../releases/latest), or from the Connect window on the website.

| File | What it is |
| --- | --- |
| `FileLink-Setup.zip` | Setup wizard. Installs the Desktop App and the `filelinkcli` command line together. Administrator permission is required. |
| `FileLink-Desktop.zip` | The Desktop App on its own. The app uses this file to update itself. |
| `FileLink.msi` | The Windows installer package that Setup downloads and checks. |

Each file has a `.sha256` file next to it so you can compare the checksum.
